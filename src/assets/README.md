# 美術素材設計文件

> 本文件記錄視覺風格決策、素材清單、生圖 prompt 及工作流程。
> 新增素材時以此為規範，確保風格一致。

---

## 視覺風格決策

| 項目               | 決定                           | 理由                                             |
| ------------------ | ------------------------------ | ------------------------------------------------ |
| 整體風格           | 台灣傳統彩券風 + 像素化        | 貼近本地彩券質感，像素化增加趣味性               |
| 色調               | 大紅底色、金黃文字與裝飾       | 沿用現有 UI 色系                                 |
| 符號渲染           | PNG sprite 取代 emoji          | emoji 跨平台不一致，pixel art 與裝飾元素視覺統一 |
| 透明底             | 全部 PNG 純白背景              | 方便疊加在不同底色上                             |
| 祥雲 tile 渲染方式 | CSS `background-image: repeat` | 裝飾性非內容圖，不需 alt text，無需 `<img>` 標籤 |
| 生圖工具           | NanoBanana                     | —                                                |

## 生圖工作流程

1. 用上方 prompt 在 NanoBanana 生成，每張產出 3–4 個版本
2. 篩選標準：像素感清晰、主體在畫面中央、純白背景乾淨
3. 存入對應目錄（如 `src/assets/symbols/sym-yuanbao.png`）
4. 更新上方清單的「狀態」欄位為 ✅
5. 素材到齊後，開始「版型精緻化實作」feature

---

## 版型精緻化預計改動範圍

（素材備齊後展開，此處先記錄預計範圍）

- Canvas symbol 渲染：`ScratchCellCanvas` 改用 `ctx.drawImage()` 載入 sprite
- 卡片外框：CSS 浮雕邊框、金屬紋理（box-shadow + gradient）
- 背景紋路：`cloud-tile.png` 做 CSS `background-image: repeat`，套在卡片背景 div
- 財神裝飾：牌堆頭部加 `caishen.png`
- 字型：引入 Noto Serif TC 或類似中文 Serif 字型
